# Desmatamento e Liberação de CO2 na atmosfera

# Objetivo
Analisar as causas e as consequências do aquecimento global, destacando como as mudanças climáticas impactam a agricultura e o meio rural, e propor práticas sustentáveis que possam ser adotadas localmente para mitigar esses efeitos.

# Justificativa
 O aquecimento global altera o clima e ameaça a agricultura e a segurança alimentar. Conscientizar a comunidade através deste projeto estimula práticas sustentáveis e transforma alunos em agentes de mudança ambiental.
